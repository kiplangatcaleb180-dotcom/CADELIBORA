# CADELIBORA Regression Checklist

- [x] **Authentication**: Registration, Login, Session Restoration, Password Change.
- [x] **RBAC**: Student vs Admin vs Super Admin permission checks.
- [x] **Academy**: Course catalog search, enrollment, lesson viewing, progress tracking, certificate generation.
- [x] **Research & Projects**: Discovery, detail views, and authenticated workspaces.
- [x] **Library & Knowledge Center**: Public resource discovery, bookmarking/saving, and personal library view.
- [x] **Community**: Discussion feeds, posting, commenting, and ownership-verified deletion.
- [x] **AI Workspace**: Neural reasoner chat, conversation history, ownership security.
- [x] **Marketplace & Services**: Products, professional services, and order history tracking.
- [x] **Global Search**: Multi-entity cross-ecosystem search.
- [x] **Analytics**: Real database metric aggregations.
- [x] **Infrastructure**: Environment validation, rate limiting, and graceful shutdown.
